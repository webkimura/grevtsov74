AI-бот для интернет-магазина

Задача

На сайте по продаже электрических соединителей не было онлайн-чата — только форма сбора контактов, которой почти никто не пользовался.

Решение

AI-бот на сайте общается с посетителями, собирает контактные данные и передаёт квалифицированный лид в Битрикс24 оператору.

Результат

5–10 обращений в неделю через бота. Раньше онлайн-обращений не было вообще.

Мониторинг серверов для сисадмина

Задача

Системный администратор проверял состояние серверов вручную — нужно было заходить на каждый и смотреть метрики.

Решение

n8n + REST API мониторит RAM, GPU, диск и Docker-контейнеры (2 сервера, ~10 контейнеров). При отклонениях создаёт оповещения в Битрикс24.

Результат

3–5 инцидентов в неделю, оповещение в течение 5 минут. Админ узнаёт о проблеме сразу.

  • n8n
  • REST API
  • Linux
  • Docker
  • Битрикс24

RAG-бот для ИТ-отдела

Задача

Пользователи звонили или писали в ИТ-отдел, оставляли заявки по телефону — неудобно и медленно.

Решение

Бот в Битрикс24 отвечает на типовые вопросы по базе знаний (RAG на локальной LLM, ~10 страниц А4). Если ответа нет — создаёт заявку.

Результат

Часть обращений закрывается ботом, пользователи общаются текстом, а не по телефону.

  • n8n
  • LLM
  • RAG
  • Битрикс24

Частые вопросы

Отвечаю честно, включая неудобные вопросы.

Вы один — потянете мой проект?

Я беру ограниченное число проектов одновременно, поэтому ваш не стоит в очереди за десятью другими. Если очередь занята, я честно называю дату, с которой смогу взяться.

Что будет, если вы заболеете или уйдёте в отпуск?

О плановом отпуске предупреждаю заранее и сдвигаю плановые задачи. На форс-мажор есть партнёры, которые могут подстраховать. Все настройки задокументированы, поэтому другой специалист при необходимости подхватит их без потерь.

Кому принадлежит код и доступы?

Вам. Исходники, доступы и описание настроек передаю по акту с первого дня. Никаких «наша платформа, вы арендуете» и привязки к подрядчику.

Сколько это стоит без всяких «от»?

После короткого созвона я называю одну сумму и фиксирую её в договоре до начала работ. Дальше она не меняется. Стартовые цены на сайте — ориентиры по направлениям, а не цена любой задачи.

У меня нет технического задания. Это проблема?

Нет, ТЗ пишу я. Вы рассказываете, как процесс устроен сейчас и что в нём мешает, я приношу документ на понятном языке, вы его правите. Работа идёт по подписанному ТЗ.

Вы работаете официально?
